# סורק 3D

אפליקציית iPhone שסורקת חלק ובונה ממנו מודל תלת־ממדי בגודל אמיתי, למדידה ולייצוא (STL, OBJ, GLB).
דורשת iPhone Pro עם LiDAR ו־iOS 17 ומעלה.

## מה יש בגרסה הזו (אבן דרך 1)

- סריקה מודרכת: מכוונים לחלק, מאשרים, מקיפים אותו.
- המודל נבנה בטלפון בגודל אמיתי (לפי ה־LiDAR).
- מידות חיצוניות של החלק, ומדידת מרחק בין שתי נקודות בלחיצה.
- כיול לפי קליבר: מקלידים מידה אמיתית, וכל המודל מתוקן לפיה.
- ייצוא STL ו־OBJ במילימטרים, ו־GLB.
- התמונות של כל סריקה נשמרות (לעיבוד מפורט בענן באבן דרך 2).

הקבצים נמצאים גם באפליקציית "קבצים" תחת "סורק 3D".

## התקנה בחינם מ־Windows

1. בעמוד [Releases](../../releases) מורידים את הקובץ `Scan3D.ipa` מהגרסה האחרונה.
2. מתקינים את [iTunes](https://www.apple.com/itunes/) (הגרסה מהאתר של Apple, לא מה־Microsoft Store) ואת [Sideloadly](https://sideloadly.io).
3. מחברים את האייפון בכבל ולוחצים "Trust" באייפון.
4. ב־Sideloadly: גוררים את `Scan3D.ipa`, מכניסים את ה־Apple ID ולוחצים Start.
5. באייפון: הגדרות ← כללי ← VPN וניהול מכשירים ← מאשרים את ה־Apple ID שלך.
6. בפעם הראשונה ש־iOS מבקש, מפעילים מצב מפתח (Developer Mode): הגדרות ← פרטיות ואבטחה ← מצב מפתח, והטלפון יופעל מחדש.

עם Apple ID חינמי ההתקנה תקפה ל־7 ימים. אחרי זה מחברים שוב ולוחצים Start ב־Sideloadly.

## איך הבנייה עובדת

כל דחיפה ל־`main` מריצה את GitHub Actions על Mac: XcodeGen יוצר את הפרויקט מ־`project.yml`,
‏xcodebuild בונה בלי חתימה, והקובץ `Scan3D.ipa` מתפרסם כ־Release. Sideloadly חותם אותו בזמן ההתקנה.
